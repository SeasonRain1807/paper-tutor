# 交付前质量门禁

完成精读后逐项检查。

## A. 文档完整性

- [ ] 确认使用的是目标论文，不是同名或引用文献。
- [ ] 识别了论文类型和研究范式。
- [ ] 如果 PDF/补充材料不完整，已明确写出边界。

## B. 理解闭环

- [ ] Background → Gap → Question → Design → Evidence → Conclusion 能连成完整链条。
- [ ] 核心方法不仅写“是什么”，还写“负责验证什么”。
- [ ] 每个核心结论都能落到具体图表，图表的「实验条件」「原文解释」标注了对应原文位置。

## C. 证据追溯

- [ ] 所有图、表都已逐张三段式解释，没有跳过或合并。
- [ ] 关键数值有来源位置。
- [ ] 关键 Claim 有 PDF 页/Fig./Table/Section 定位。
- [ ] 没有从低清图表凭空估计精确数值。
- [ ] 百分比若为自行计算，明确说明计算来源。

## D. 防幻觉

- [ ] 原文未写的信息没有被补造。
- [ ] `[原文事实] / [作者解释] / [Codex推断] / [待验证假说]` 区分清楚。
- [ ] 相关性没有被写成因果。
- [ ] 模拟没有被写成实验验证。
- [ ] proxy 没有被写成直接物理量。

## E. 批判性

- [ ] 「不足与思考」不是泛泛说“样本量小、需要更多实验”。
- [ ] 每个补实验/分析建议都说明补哪条证据链。
- [ ] 同时识别“论文支持什么”和“不支持什么”。

## F. 可复用资产

- [ ] 「可学习的学术表达」「新科学问题」「对我的当前课题启发」至少给出了一类。
- [ ] 若用户提供课题，「对我的当前课题启发」与其课题明确关联。
- [ ] 没有把“可借鉴”写成“可以直接复制”。

## G. 两份笔记与网页的一致性

- [ ] 一页结论卡中的核心发现与完整笔记一致。
- [ ] 完整笔记中的关键 Claim 都能在原文中定位到具体页/图/表。
- [ ] `3_精读阅读页.html` 中的原文与笔记引用同一套位置（PDF p.X / Section / Fig. / Table），不出现两套说法。
