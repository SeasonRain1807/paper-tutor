# 逐句翻译规范

译文的目标是让中文读者在不回看英文的情况下完整理解这一段，同时能在回看时逐句对上。因此译文必须**句子对齐、信息守恒**。

## 基本单位：句

1. 以英文句末标点（`. ? !`）和分号/冒号为界切句；分号在中文里通常译为逗号，但仍算同一句。
2. 每句英文对应一句（或一组紧邻的）中文，顺序一致。**不允许**把两句合成一句来"读起来更顺"，也不允许一句拆成两句来"更通顺"。
3. 英文用破折号、括号插入的内容，中文保留插入结构；实在无法保留时，改为独立短句并放在原句之后，不得删除。
4. 段落开头的小词（`However,`、`Thus,`、`In contrast,`）必须译出，它们承载论证转折，不是语气词。

## 信息守恒

| 必须译出 | 说明 |
|---|---|
| 所有限定词 | `may`、`often`、`up to`、`roughly`、`in practice` 不能省略，它们决定了命题强度 |
| 所有否定与双重否定 | `not uncommon` 不等于"罕见" |
| 条件与让步 | `unless`、`provided that`、`even if`、`while` 的关系必须保留 |
| 范围与量词 | `most`、`a majority of`、`several`、`at least` 不可互换 |
| 时态所传达的信息 | `has been shown`（已有共识）与 `we show`（本文主张）要区分 |
| 引用标记 | `[12]`、`(Smith et al., 2020)` 原样保留在对应位置 |

不允许：添加原文没有的解释、评价、背景补充（这些放注释）、把"作者认为"改写成客观事实、把不确定的表述译成确定。

## 术语

- 首次出现的核心术语：中文（English original），例如"稀疏注意力（sparse attention）"；同段后续只写中文。
- 全篇统一：同一术语只用一个译法，术语表放进该段的 `analysis.terms`，由构建器汇总。
- 已被广泛接受的译法优先（attention → 注意力，embedding → 嵌入，ablation → 消融）；没有通行译法时保留英文，不要生造。
- 缩写首次出现给全称：`LLM（Large Language Model，大语言模型）`，之后直接用缩写。

## 公式、符号与代码

- 行内符号原样保留：`O(n²)`、`α`、`x_t`、`‖·‖`。不要改写成文字描述。
- 独立公式单独成段（`kind: "equation"`），`en` 保留公式原文，`zh` 给出读法（"其中 d 为维度，T 为序列长度"），不在 `zh` 里重排公式。
- 变量名、函数名、超参数、数据集名保持英文原样，不翻译（`batch size` 可写"批大小（batch size）"，但 `ResNet-50` 不译）。
- 单位与数字：`1.2×`、`3.4 pp`、`p < 0.05` 原样；中文里数字与单位之间不加空格的习惯与原文保持一致即可，不擅自改。

## 语序与可读性

- 允许：拆分英文长定语为前置短句、把被动改主动、补出指代对象（`it` → "该模型"、"这一结论"）。
- 不允许：改变因果方向、把并列改递进、把必要信息挪到注释里。
- 目标长度：中文约为英文词数的 0.55–0.75 倍字符量。明显低于 0.4 多半是漏译，明显高于 1.0 多半是加料——`check.py` 会给出警告。
- 译文用学术书面语，避免"我们认为"式口语；作者的第一人称 `we` 按语境译作"本文"或"我们"，全篇统一。

## 自检清单（每段译完过一遍）

- [ ] 英文几句，中文几句（允许 ±1 的结构调整，超出就要复查）。
- [ ] 每个从句都有落点，没有"略"。
- [ ] 转折词、限定词、否定都译出了。
- [ ] 引用编号位置正确。
- [ ] 数字、单位、比较基准与原句一致。
- [ ] 术语与全文统一，首次出现带英文。
- [ ] 没有把注释内容写进译文。
- [ ] 读一遍中文：作为独立段落能读懂，且没有引入英文里不存在的判断。

## 反例

原文：
> While prior work has shown that sparse attention reduces memory, it remains unclear whether it preserves accuracy at scale.

- ❌「先前工作表明稀疏注意力能降低内存占用，但在大规模下能否保持精度尚不清楚。」——丢了 `at scale` 与前句的让步关系，`While` 被吞。
- ✅「尽管已有工作表明稀疏注意力能够降低内存占用，但它在更大规模下是否仍能保持精度，目前仍不清楚。」

原文：
> We do not claim that our method is optimal.

- ❌「我们的方法并非最优。」——丢掉了"不主张"这一元话语，把作者的态度改成了事实判断。
- ✅「本文并不主张我们的方法是最优的。」
